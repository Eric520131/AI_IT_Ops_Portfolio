## Prompt Created

### Prompt 008 - IT Documentation Generator Assistant

This prompt is designed to help turn technical notes, screenshots, command outputs, issue details, and troubleshooting steps into clear professional IT documentation.

It can help create:

- Troubleshooting documentation
- Incident reports
- Root cause analysis notes
- Standard operating procedures
- User guides
- System setup guides
- Server health check reports
- Backup investigation reports
- Network troubleshooting reports
- Change documentation
- Handover notes
- Project documentation

## IT Documentation Areas Learned

### 1. Incident Report

An incident report documents what happened, who was affected, what troubleshooting was done, what the root cause was, and how the issue was resolved.

This is useful for IT Support, Service Delivery Managers, and future reference.

### 2. Root Cause Analysis

Root cause analysis helps identify why an issue happened.

It is not only about fixing the issue, but also understanding how to prevent it from happening again.

### 3. Standard Operating Procedure

A standard operating procedure provides repeatable steps for common IT tasks.

Good SOPs help reduce mistakes and improve consistency.

### 4. Troubleshooting Documentation

Troubleshooting documentation records the issue, checks performed, findings, resolution, and verification steps.

This is important when working with other engineers or handing over cases.

### 5. Health Check Report

A health check report summarizes server or system status, including uptime, disk space, services, event logs, backup status, security status, issues found, and recommendations.

### 6. Handover Notes

Handover notes help another engineer understand the current status of a task, pending items, risks, and next actions.

## Documentation Structure Learned

A professional IT document should include:

1. Document Title
2. Purpose
3. Scope
4. Background
5. Issue Summary
6. Environment
7. Steps Performed
8. Findings
9. Root Cause
10. Resolution
11. Verification Steps
12. Risk or Impact
13. Preventive Actions
14. Notes for Future Reference
15. Final Summary
