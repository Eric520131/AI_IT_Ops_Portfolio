## Prompt Created

### Prompt 001 - IT Incident Troubleshooting Assistant

This prompt helps analyze IT incidents using a structured format.

It can be used when checking:

- User issues
- Error messages
- Screenshots
- Log files
- Backup failures
- Windows issues
- Server issues
- Network issues
- Shared folder access problems

## Skills Practiced

## Why This Is Useful

This prompt can help me think like an IT Support Engineer or System Administrator.

Instead of giving random answers, the prompt guides the AI to analyze problems step by step.

The structure includes:

1. Problem Summary
2. Possible Root Causes
3. Questions to Confirm
4. Step-by-Step Troubleshooting Plan
5. Commands or Tools to Check
6. Risk Level
7. Suggested Fix
8. Documentation Notes
