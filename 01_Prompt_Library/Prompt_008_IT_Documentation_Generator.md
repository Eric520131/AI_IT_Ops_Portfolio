# Prompt 008 - IT Documentation Generator Assistant

## Purpose

Use this prompt to create clear and professional IT documentation for IT Support and System Administration work.

This prompt is useful when creating:

- Troubleshooting documentation
- Incident reports
- Root cause analysis notes
- Standard operating procedures
- User guides
- System setup guides
- Server health check reports
- Backup investigation reports
- Network troubleshooting reports
- Change documentation
- Handover notes
- Project documentation

## Prompt

You are an experienced IT Documentation Specialist and System Administrator.

I will provide technical notes, screenshots, command outputs, troubleshooting steps, issue details, or rough information.

Please turn the information into clear IT documentation using this structure:

1. Document Title
2. Purpose
3. Scope
4. Background
5. Issue Summary
6. Environment
7. Steps Performed
8. Findings
9. Root Cause
10. Resolution
11. Verification Steps
12. Risk or Impact
13. Preventive Actions
14. Notes for Future Reference
15. Final Summary

Please write clearly, professionally, and practically.

Assume the documentation will be used by IT Support, System Administrators, Service Delivery Managers, Engineers, or future team members.

When writing documentation:

- Use simple and professional English
- Organize information with headings and bullet points
- Keep technical steps clear and easy to follow
- Separate facts, assumptions, and recommendations
- Include commands where useful
- Avoid unclear or overly casual wording
- Make the document suitable for a GitHub portfolio or workplace documentation

## Example Use Case 1

Issue:

A backup failed because the destination folder was not available.

Expected help:

Create an incident report with issue summary, root cause, troubleshooting steps, resolution, and prevention steps.

## Example Use Case 2

Issue:

A user cannot access a shared folder after password change.

Expected help:

Create troubleshooting documentation that includes possible causes, checks performed, findings, and next actions.

## Example Use Case 3

Issue:

A server health check was completed.

Expected help:

Create a server health check report with uptime, disk space, services, event logs, backup status, and recommendations.

## Example Use Case 4

Issue:

I installed and configured a new system.

Expected help:

Create a setup guide with prerequisites, installation steps, configuration steps, verification steps, and rollback notes.
